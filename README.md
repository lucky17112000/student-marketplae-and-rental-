3.every()
.every() হলো JavaScript-এর একটি Array Method।
এর কাজ হলো Array-এর প্রতিটি element একটি নির্দিষ্ট condition পূরণ করছে কি না check করা।
.every() দিয়ে আমরা array-এর প্রতিটি element একে একে check করি।
